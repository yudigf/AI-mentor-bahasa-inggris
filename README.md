# Mentor Bahasa Inggris Virtual (AI Agent)

Asisten & Mentor belajar Bahasa Inggris virtual berbasis AI yang terintegrasi dengan Telegram Bot dan Google Gemini.

## Fitur Utama
- **Latihan Reading**: Pembuatan teks bacaan dan pertanyaan pemahaman interaktif.
- **Latihan Speaking**: Tugas berbicara terarah untuk pemula.
- **Latihan Listening**: Pembuatan dialog interaktif multi-speaker dengan Text-to-Speech (TTS) Gemini.
- **Evaluasi Writing**: Koreksi tata bahasa (grammar) dengan penjelasan bahasa Indonesia.
- **Evaluasi Speaking**: Analisis pelafalan (pronunciation) dari rekaman Voice Note (VN).
- **Tips Belajar**: Tips harian praktis untuk meningkatkan kemampuan bahasa Inggris.
- **Laporan Belajar (PDF)**: Pembuatan dokumen laporan belajar berkala.
- **Pengingat Harian**: Notifikasi latihan otomatis terjadwal.

## Menjalankan Aplikasi
```bash
# Mode Telegram Bot
uv run main.py

# Mode Terminal CLI
uv run main.py --cli
```
